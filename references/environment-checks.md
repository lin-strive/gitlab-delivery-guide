# 环境检查与节点接入

按当前步骤选读；系统、版本、地址和路径以本项目实际情况为准。

## GitLab 与仓库

优先已有 GitLab 工具、CLI 和 Git 身份。GitHub 连接不是 GitLab 连接；SSH 克隆成功不证明 API 认证可用。

```text
python <skill-dir>/scripts/gitlab_probe.py <project-url> --parse-only
python <skill-dir>/scripts/gitlab_probe.py <project-url> --ref <inspection-branch> --output <new-local-inventory.json>
```

脚本仅用 Python 标准库。Token 从 GITLAB_TOKEN 或 --token-env 指定变量读取，不把值放入参数；私有 CA 用 --ca-file；自定义 API 用 --api-base。SSH 端口不能推导 Web 端口，Web 子路径不能随意删掉。

只有用户明确选择既有 HTTP 实例时才用 --allow-http，不能为绕过 HTTPS 错误降级协议或忽略证书。无权列 Runner 时记 unknown，不能判断为没有；根目录线索不代替全仓调查。已有登录浏览器可在工具权限范围内补充只读调查。

SSH publickey 失败先检查已有公钥、ssh-agent 和实际 IdentityFile；必要时仅当前仓库指定已有身份。不立即重建密钥，不把本机私钥路径写入共享模板。远程主机核验真实指纹。

## Runner 与访问链路

分别验证领取任务、拉取源码、下载依赖、上传/下载产物、部署访问和 VM 到应用的访问。一个通道正常不证明其余正常。

记录实际 GitLab/Runner 版本，按对应官方文档选择注册与配置方法；关键字被识别不代表许可、项目权限和执行器支持完整行为。最小 CI 作业输出安全的节点身份、架构和工具版本，不打印完整环境或注册配置。

Shell 准备失败查看真实日志：sh 可能指向 dash，需按 Runner 版本核对 POSIX 转义；PowerShell 输入方式、编码和会话分别排查。不随意修改用户登录/退出文件。并发限制不能代替部署到验收的环境锁。

## 部署目标

先调查服务、端口、目录/命名空间、数据资源与主机资源，确认测试环境的隔离边界，不复用其他项目的配置与数据。按实际架构核验部署工具和运行库，记录基础镜像或运行时的版本、来源与摘要。

备份应可定位、非空且权限受限；分别说明文件、应用镜像和数据库恢复范围。恢复镜像不等于数据库迁移可逆，也不等于服务与功能已经恢复。

## VM 与网络

记录实际 OS/架构、VM ID、hostname、连接方式、测试 Runner 标签与会话条件。检查持久化安装，Live/临时根文件系统不作为长期节点。核对 CPU、内存、磁盘、负载，再设置任务资源。

浏览器、原生客户端、SDK 和驱动的架构分别核验；网页能用不能推出设备能用。NAT 下 VM 可主动领取 GitLab 作业；桥接取决于访问方向和局域网设备需求。区分 Agent 的远程维护通道与 Runner 的任务执行通道。

连接失败先检查地址、路由、端口、应用层握手和服务。TCP 建连不等于 SSH 握手成功；锁屏画面不自动证明超时原因。代理、DNS、浏览器和命令行网络分别排查。

## 桌面与框架

- Windows 可见模式需实际交互会话，Session 0 服务不能当作可见桌面；验证选用的启动机制与重启后行为。
- Linux 核对 X11/Wayland 与用户权限，使用真实 DISPLAY/XAUTHORITY 和会话总线，不能复制其他 VM 的值。用户服务自启动不等于桌面已自动登录。
- 无人值守需确认锁屏、休眠和登录策略；用户要求时才调整并保存原值。先读已有显示管理器配置，自动登录不需要清空 SSH/sudo 密码。
- 浏览器优先使用用户指定且兼容的安装；预检实际执行可见性定位、脱敏截图和必要框架接口。只打印版本不够。需要更换时使用适配架构与运行库的官方来源，记录版本和摘要，不固定某一版本。
- 虚拟 GPU 问题可在隔离测试配置中验证软件渲染等参数，保留可见模式与真实断言，不全局套用到其他节点。
- 原生桌面需对应系统的适配器，网页框架不自动支持任意原生应用；先验证控件访问、截图与启动能力。

## 执行信任与缓存

系统可能分别拦截程序、脚本入口或共享库。根据实际错误核验来源和文件标签，按管理员认可的具体文件或安装包机制处理；不关闭全局保护、不换解释器规避拒绝执行。

需要人工时一次列出已核验的准确文件与预期结果，不凭猜测追加授权；正确引用路径。更新后的文件重新核验，主程序通过不代表子进程/共享库都通过。

工作区清理会删除已核验工具时，可按锁文件摘要建立稳定用户级缓存并验证身份；依赖变化建立新缓存。缓存不能成为忽略版本或递归信任整个目录的理由。环境变量优先配置数据或 EnvironmentFile，避免反复生成待执行的环境脚本。
